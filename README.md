# Satoshi Race

Jeu de course HTML5 autonome, sans dépendance externe.

## Modification

La vitesse augmente progressivement au fil de la distance parcourue grâce à une courbe d’accélération douce. La vitesse de départ reste fixée à `4`, le plafond reste à `14`, et le nitro conserve son multiplicateur existant.

## Lancer le jeu

Ouvrir `index.html` dans un navigateur moderne.

## Déploiement Vercel

Le projet est un site statique. Il peut être importé directement depuis ce dépôt GitHub dans Vercel, sans commande de build ni répertoire de sortie particulier.
